- DIFF2-D2 (2026-11-05, F1): the InitGame vehicle-model preload (B 0x100A1620; ours `vehlabels::preload`) probes every model with `0x0248 HAS_MODEL_LOADED` and releases with `0x0249` only the vehicle models GTA's streamer happens to hold at that moment; the probe sequence is compared in full, the set of released vehicle models (400–611) is accepted in `flow_join` / `gamemode_restart`. Evidence: 14 original runs of the same scenario release 22 models each, but which ones varies (model 401 is missing in 2 of 14, 507 / 527 / 547 / 551 and others come and go); ours releases 23 with the same variation.
- DIFF2-D3 (2026-11-05, F1): DIFF-2 step `explosion` (RPC 79), screenshot component only. The explosion itself is identical (`0x0948 [1983.4,1343.2,15.4,12,0]` → `CExplosion::AddExplosion` shake 0, trace and state MATCH in every run); the changed grid cells are the local ped's idle-breathing silhouette. - DIFF2-CAL (2026-11-05, F1): DIFF-2 judges against 6 fresh original runs plus up to 6 earlier complete original runs of the same scenario (started after the last change of rpcfire.pwn / diffbase.pwn / e2eprobe.pwn / rpc-coverage.sh, same samp.dll and tracer hashes; defaults of `rpc-coverage.sh`, `--reuse-orig`).
